Mars

Hack the Mars Base

Die Forschungsstation auf dem Mars hat ein Login-System. Leider wurde es unter Zeitdruck gebaut. Finde in jedem Level einen Weg hinein und sammle alle 5 Flags. Entwicklertools (F12) sind ausdrücklich erlaubt.

Level 1 von 5 · Aufklärung

Der vergessene Kommentar

Das Login-Portal der Station ist gerade erst live gegangen. Der Entwickler war in Eile – vielleicht hat er beim Testen etwas liegen lassen, das niemand sehen sollte.

Ziel: Melde dich als admin an.

Level 2 von 5 · Client-Side

    
Der Wächter im Browser

    
Nach dem Vorfall wurde der Kommentar entfernt. Neues Konzept: Damit der Server
      entlastet wird, prüft jetzt der Browser selbst, ob das Passwort stimmt. Und es ist „verschlüsselt“.

    
Ziel: Finde das Admin-Passwort und melde dich als admin an.

Level 3 von 5 · Session

    
Der Gastausweis

    
Inzwischen prüft ein Server die Passwörter. Für Besucher gibt es einen
      Gastzugang: gast / gast. Der Admin-Bereich bleibt Gästen natürlich verschlossen.
      Oder? Der Server merkt sich deine Sitzung in einem Cookie.

    
Ziel: Öffne die Admin-Konsole.

Level 4 von 5 · Injection

    
Die Datenbank plaudert

    
Version 3 speichert Benutzer in einer SQL-Datenbank. Die Sitzung ist jetzt sicher signiert.
      Aus Versehen ist aber noch der Debug-Modus an und zeigt jede SQL-Abfrage im Log.
      Das Admin-Passwort ist lang und zufällig, Raten ist zwecklos.

    
Ziel: Melde dich als admin an, ohne das Passwort zu kennen.

    

      

        MARS-BASE // PORTAL v3.0 · DEBUG=1
        
        
        
      

      

    

    

    

    

  


  
  

    
Level 5 von 5 · Kryptografie

    
Das geleakte Backup

    
Alle Lücken sind gestopft, Prepared Statements überall. Dumm nur, dass jemand eine
      Sicherung der Benutzertabelle auf einem offenen Server vergessen hat. Die Passwörter sind gehasht,
      also eigentlich sicher.

    
-- users.bak  (mars-base, 2024-05-30)
-- algo: sha1(password)
+----+----------+------------------------------------------+
| id | user     | password_hash                            |
+----+----------+------------------------------------------+
|  1 | admin    | 327156ab287c6aa52c8670e13163fc1bf660add4 |
|  2 | kowalski | 5627901a8bb14d1a606ad3ae51c72de87d2c79d1 |
|  3 | gast     | 0e110f6bafda86368db93664dfc5cdc3c05471ac |
+----+----------+------------------------------------------+

    
Ziel: Knacke den Hash und melde dich als admin an.
